Model basis & references. Throughput math is a simplified version of the inference-economics framework from Erdil & Epoch (2025) — per-token decode time = max(memory-bw, compute, network) plus collective latency, with batch size traded against activation/network cost. Price-decline curves follow Epoch AI's LLM inference price trends (median ~50× per year, post-2024 ~200×). TCO categories follow the SemiAnalysis InferenceMAX decomposition (chips, networking BoM, datacenter, power). See Epoch's inference-economics blog post for the latency-cost Pareto-frontier methodology this dashboard echoes. All numbers are illustrative; tune the parameters to your own situation.
